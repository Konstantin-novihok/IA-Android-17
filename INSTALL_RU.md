ПЕРВАЯ УСТАНОВКА IA-Android-17

Состояние: ранняя оболочка интерфейса. Чат, настройки и вызов системного выбора файла доступны. Модель Qwen и обработка файлов пока НЕ подключены. APK не содержит весов модели.

ПОЛУЧИТЬ APK
1. Откройте https://github.com/Konstantin-novihok/IA-Android-17
2. Перейдите в Actions → Android Debug APK.
3. После автоматического запуска откройте последнюю задачу. Либо нажмите Run workflow.
4. Убедитесь, что выполнение завершилось успешно.
5. Внизу страницы откройте Artifacts и скачайте IA-Android-17-debug-apk.
6. Распакуйте ZIP, извлеките APK.
Если сборка красная/failed, APK не создаётся: пришлите лог Build debug APK.

УСТАНОВКА НА ТЕЛЕФОН
1. Передайте APK на Samsung через USB или другое выбранное вами средство.
2. В «Мои файлы» откройте APK.
3. Если Android спросит, временно разрешите установку неизвестных приложений именно для используемого файлового менеджера/источника.
4. Нажмите «Установить», затем «Открыть».
5. Устанавливайте только APK из своего репозитория и доверенного запуска CI. Это debug build, не релиз магазина.
Идентификатор debug-пакета: com.iaandroid17.debug.

КНОПКИ И ПАРАМЕТРЫ
ЭКРАН «Помощник»
• «Файл» — открывает системный документный picker. Сейчас выбирается объект, но текст из него не читается и не анализируется.
• «Сообщение» — поле ввода.
• «➤» — добавляет реплику пользователя и статусный демонстрационный ответ. Это НЕ ответ модели.
• «Настройки» / нижняя вкладка «Настройки» — переход к конфигурации.
• Нижняя вкладка «Помощник» — возврат к диалогу.

ЭКРАН «Настройки»
• «Основная модель» — план PF-005 Qwen3-8B Q4_K_M. Модель скачивается отдельно после подготовки runtime и проверки формата/происхождения/лицензии.
• «Профиль разрешений»: ограниченный / расширенный / максимально доступный. Пока переключатель демонстрационный, реальные права не выдаются. В будущем задаст уровень возможностей; разрешения Android всё равно контролирует пользователь.
• «Лимит контекста»: 2 048–16 384 токенов. Пока не влияет на вычисления. После интеграции runtime определит рабочий предел контекста; большее значение обычно повышает расход RAM.
• «Выбрать файл» — открывает системный выбор документа.
• «О локальной обработке» — поясняет статус прототипа.
• «К помощнику» — возвращает на главный экран.

НАСТРОЙКИ СЕЙЧАС
Оставьте значения по умолчанию: runtime ещё не подключён. Общие 16 ГБ RAM — не объём, целиком доступный модели: память нужна ОС, KV cache и рабочим буферам; будем проверять измерениями.

ДОСТУП И ПРИВАТНОСТЬ
Системный picker позволяет выбрать доступные документы. Приложение не получает универсальный доступ к данным других приложений; Android защищает приватные каталоги. Не включайте широкие разрешения, если конкретная функция этого не требует.

СЛЕДУЮЩИЙ ЭТАП
1. Интеграция llama.cpp через изолированный inference interface и Android JNI/NDK.
2. Проверка GGUF сборки модели, источника, лицензии и SHA-256.
3. Контролируемая загрузка/выгрузка модели и диагностика RAM/нагрева.
4. Извлечение текста из документов с ограничениями ресурсов.
5. Локальная память/RAG и безопасный инструментальный контроллер.
