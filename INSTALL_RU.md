# IA-Android-17 — установка и использование

Локальный ИИ-помощник для Android. Нейросеть (Qwen3-8B Q4_K_M через llama.cpp) работает **на телефоне**, без серверов.

## Что нужно
- Телефон на Android 13+ с архитектурой arm64 (Samsung Galaxy S26 Ultra подходит).
- Свободно ≈ 7 ГБ памяти и желательно 8+ ГБ оперативной памяти (у модели Q4_K_M ≈ 5 ГБ).
- Wi-Fi для однократной загрузки модели.

## 1. Получить APK
1. Откройте репозиторий → вкладка **Actions** → **Android Debug APK**.
2. Выберите последний запуск с зелёной отметкой (или нажмите **Run workflow**).
3. В разделе **Artifacts** скачайте `IA-Android-17-debug-apk` и распакуйте архив — внутри `.apk`.

Сборка занимает 10–25 минут: вместе с приложением компилируется движок llama.cpp.

## 2. Установить на Samsung
1. Передайте `.apk` на телефон.
2. «Мои файлы» → нажмите на APK → разрешите установку из этого источника → **Установить**.
3. После установки отключите разрешение «Установка неизвестных приложений» для источника.

## 3. Первый запуск: установить модель
1. Вкладка **Настройки → Получить модель**.
2. Включите **«Разрешить интернет для загрузки модели»**.
3. Нажмите **Скачать** (≈ 5 ГБ). Загрузку можно остановить и продолжить позже. Не закрывайте приложение и не отключайте Wi-Fi.
4. По окончании приложение проверит SHA-256 файла. Сообщение «SHA-256 совпала ✓» значит, что файл целый.
5. Выключите интернет-переключатель.

Своя модель: **Файл с телефона…** — выберите любой `.gguf` (он будет скопирован в память приложения).

## 4. Работа
1. Вкладка **Помощник** → напишите вопрос → ➤. Первый ответ идёт дольше: модель загружается в память.
2. **■** останавливает ответ.
3. **📎** прикрепляет документы; они появляются на вкладке **Документы**.

## Кнопки и настройки
| Элемент | Что делает |
|---|---|
| 💬 Помощник | Чат |
| 📄 Документы | Список прикреплённых файлов, включение/выключение каждого, удаление |
| ⚙️ Настройки | Модель, ресурсы, безопасность |
| Загрузить / Выгрузить | Загружает модель в память / освобождает память |
| Новый | Начать новый диалог |
| 📎 | Выбрать документы (TXT, MD, CSV, JSON, HTML, код, PDF с текстом, DOCX, PPTX, XLSX, ODT) |
| ➤ / ■ | Отправить / остановить ответ |
| 💭 Рассуждения | Показать ход мыслей модели (только в режиме thinking) |
| Скачать | Загрузка выбранной по ссылке модели, с докачкой и проверкой SHA-256 |
| Лимит контекста | Сколько токенов «помнит» модель. Больше — медленнее и больше памяти (на 4096 ≈ 0,6 ГБ KV-кэша) |
| Потоков процессора | Скорость против нагрева. Применяется при следующей загрузке модели |
| Максимум токенов в ответе | Длина ответа |
| Температура | 0 — строго и предсказуемо, выше — разнообразнее |
| Режим рассуждений | Точнее на сложных задачах, но заметно дольше |
| Использовать документы | Добавлять ли фрагменты документов в запрос |
| Сохранять историю | Хранить диалог в памяти приложения |
| Защита от перегрева | Остановить ответ при сильном нагреве по данным Android |
| Системные настройки | Открывает системную страницу приложения (права, память) |

## Права и безопасность
- Приложение читает **только выбранные вами файлы**; доступа ко всей памяти нет.
- Интернет — только для загрузки модели и только по вашему разрешению.
- Микрофон, камера, контакты, геолокация не используются.
- ИИ **не выполняет команды** на телефоне: в этой версии он лишь читает текст и отвечает.
- Содержимое документов считается недоверенным: инструкции внутри файлов не исполняются.

## Ограничения этой версии
- Не поддерживается: OCR для сканов и изображений, старые .doc/.xls/.ppt, архивы.
- Поиск по документам — по словам (BM25), без эмбеддингов.
- Загрузка модели идёт, пока приложение открыто; в фоне Android может её прервать (докачка сработает).
- Скорость ответа зависит от телефона; ожидайте единицы токенов в секунду на 8B.
- Сборка проверялась частично: нативный код — компиляцией против заголовков llama.cpp, логика — тестами; запуск на реальном телефоне ещё не проверялся.
