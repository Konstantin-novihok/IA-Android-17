# IA-Android-17

Локальный Android AI-помощник. Все исходники проекта находятся в этом репозитории.

## Первый этап

- Kotlin + Jetpack Compose
- Настройки приложения и локальных моделей
- Импорт документов через системный Android picker
- Основа безопасного tool routing
- CI-сборка debug APK

## Состояние

Начальная оболочка приложения. Подключение и проверка llama.cpp и модели Qwen3-8B Q4_K_M — отдельный этап. До появления подтверждённой runtime-интеграции приложение не заявляет, что генерирует ответы локальной LLM.

## Сборка

Откройте проект в Android Studio (JDK 17+), либо запустите GitHub Actions workflow **Android Debug APK**. Подробности: [INSTALL_RU.md](INSTALL_RU.md).

## Безопасность

Документы обрабатываются как недоверенные данные. Действия с последствиями требуют отдельной авторизации/подтверждения. Доступы запрашиваются по мере необходимости.
